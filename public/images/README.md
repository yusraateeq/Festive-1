## Tips

- Recommended size: **1280×960 (4:3)**, JPG or WebP.
- Keep each file under **~200 KB** for fast page loads
  (compress at site like tinypng.com or squoosh.app).
- Prefer natural-light, daytime AND evening-lit shots — they convert best.
- Until a file appears, the site shows an elegant branded placeholder instead
  of a broken image — nothing looks unfinished to visitors.
